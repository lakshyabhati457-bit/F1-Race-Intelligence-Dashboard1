# Formula 1 Race Intelligence — Web Integration

This is the adapted **Creativo Bootstrap template** for the Formula 1 Race Intelligence Dashboard Analysis Report. It includes a project description, analysis overview, embedded Tableau Dashboard and Story, methodology, and direct links to both Tableau Public views.

## Tableau views integrated
- Dashboard: https://public.tableau.com/shared/D3GGP2B5P?:display_count=n&:origin=viz_share_link
- Story: https://public.tableau.com/shared/6QBSBH2QP?:display_count=n&:origin=viz_share_link

## Run locally
1. Extract the ZIP file.
2. Open the `Creativo` folder.
3. Double-click `index.html` to preview the static website, or use a local server:
   - Open Command Prompt in the folder.
   - Run `python -m http.server 8000`
   - Open http://localhost:8000
4. Keep an internet connection available so the published Tableau views and web fonts can load.

## Deploy / submit
Upload the contents of the `Creativo` folder to your GitHub repository. For GitHub Pages, make sure `index.html` is in the published root. Tableau views remain hosted by Tableau Public.

## Description
Formula 1 Race Intelligence is an interactive data analytics project that uses Tableau to explore driver performance, team rankings, race circuit locations, reliability, tyre compound usage, and championship insights. This website integrates the published Tableau dashboard and Story into a single responsive interface and describes the project workflow from data connection and preparation to visualization and storytelling.
