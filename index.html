How It Was Built

Methodology & Project Deliverables

The project workflow connects the supplied Excel workbook to Tableau, prepares and relates data, creates visualizations, assembles a dashboard and Story, and embeds the published views in a responsive webpage.

  1. Data connection: imported the Formula 1 Excel dataset into Tableau and reviewed its five sheets.
  2. Data preparation: checked fields and established the relationship between race results and circuit information where needed.
  3. Data visualization: created nine visualizations for driver performance, team ranking, race locations, reliability, tyre usage, and other race measures.
  4. Dashboard design: arranged the charts into an interactive dashboard for a consolidated view of race intelligence.
  5. Storytelling: created a Tableau Story to present the analysis in a logical narrative.
  6. Web integration: embedded the published Tableau Dashboard and Story into this webpage with direct links as a fallback.
